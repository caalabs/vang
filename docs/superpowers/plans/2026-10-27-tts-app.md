# App TTS tiếng Việt (ElevenLabs) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PWA cho iPhone: dán kịch bản tiếng Việt → AI sửa → thêm cảm xúc → tạo audio ElevenLabs bằng key của người dùng.

**Architecture:** SPA tĩnh, không server. Mọi key (ElevenLabs, Gemini, Claude) + lịch sử nằm trong IndexedDB trên iPhone; trình duyệt gọi thẳng cả 3 API (CORS đã kiểm chứng ở Task 0). 3 tab là state trong `App.tsx`, không router. Logic thuần (chọn account, phân loại lỗi, kiểm tra tag) nằm ở `src/lib/` để test bằng Vitest.

**Tech Stack:** Vite (`create-vite` template `react-ts`), React, Tailwind v4 (`@tailwindcss/vite`), Vitest, idb-keyval. Gọi API bằng `fetch`, không thêm SDK, không router, không PWA plugin.

**Spec:** `docs/superpowers/specs/2026-10-27-tts-app-design.md`

## Global Constraints

- Mọi chữ hiển thị là tiếng Việt.
- Model TTS: `eleven_v4` (mặc định), `eleven_flash_v2_5` (Nháp). Không dùng `eleven_multilingual_v2` (không có tiếng Việt).
- Kịch bản tối đa 5.000 ký tự; vượt → chặn nút Tạo, hiện "Tối đa 5.000 ký tự".
- Adam voice_id: `pNInz6obpgDQGcFmaJgB`, luôn đứng đầu danh sách giọng.
- App không có server, không màn đăng nhập. Mọi key chỉ nằm trong IndexedDB trên máy.
- Claude model: `claude-sonnet-5-5`, header bắt buộc `anthropic-dangerous-direct-browser-access: true`. Gemini model: `gemini-flash-latest`.
- `FLASH_RATE = 0.5`; v4 = 1 credit/ký tự. `MODEL_FULL = 'eleven_v4'`.
- Mọi đường dẫn trong plan (`lib/...`, `components/...`) nằm dưới `src/`.
- Input font ≥ 16px, vùng chạm ≥ 44px, padding `env(safe-area-inset-*)`.
- Tự đặt tên key: `Acc N` (N = số lớn nhất hiện có + 1).

## Review Focus

1. **Nháp Flash với kịch bản có tag**: Flash sẽ đọc to chữ "[excited]". Phải `stripTags` trước khi gửi, và tính credit trên text đã bỏ tag. Test ở Task 2.
2. **Account 🟡 đã qua ngày reset**: phải được chọn lại, không bị bỏ qua mãi. Test ở Task 2.
3. **Mọi account đều hết hoặc bị khoá**: dừng sau khi thử hết mỗi account đúng 1 lần, báo "Hết credit ở tất cả account" thay vì lặp vô hạn. Test ở Task 2.
4. **AI "Tự thêm cảm xúc" lén sửa chữ**: bỏ hết tag rồi so text (chuẩn hoá khoảng trắng) với bản gốc; khác thì từ chối. Tag lạ do AI tự chế thì bị lọc bỏ. Test ở Task 6.
5. **Dán key lẫn khoảng trắng, dòng trống, key trùng**: trim, bỏ dòng trống, bỏ trùng với nhau và với key đã lưu. Test ở Task 3.

### Task 2: Logic ElevenLabs và chọn account

**Files:**
- Create: `lib/types.ts`, `lib/accounts.ts`, `lib/elevenlabs.ts`
- Test: `lib/accounts.test.ts`, `lib/elevenlabs.test.ts`

**Interfaces:**
- Produces (`lib/types.ts`):
  ```ts
  export type ModelId = 'eleven_v4' | 'eleven_v3' | 'eleven_flash_v2_5'
  export type AccountStatus = 'ok' | 'empty' | 'banned'
  export type Account = { id: string; label: string; key: string; used: number; limit: number; resetAt: number | null; status: AccountStatus; checkedAt: number }
  export type Voice = { voice_id: string; name: string; preview_url: string | null }
  export type VoiceSettings = { stability: 0 | 0.5 | 1; speed: number }
  ```
- Produces (`lib/accounts.ts`):
  - `MODEL_FULL: ModelId` (từ Task 0), `MODEL_DRAFT = 'eleven_flash_v2_5'`
  - `stripTags(text: string): string` — bỏ mọi `[...]`, gộp khoảng trắng thừa
  - `textForModel(text: string, model: ModelId): string` — Flash → `stripTags`, còn lại giữ nguyên
  - `estimateCredits(text: string, model: ModelId): number` — `textForModel(...).length` × hệ số (v4 = 1, Flash = hệ số đo ở Task 0), làm tròn lên
  - `remaining(a: Account): number`
  - `isUsable(a: Account, now: number): boolean` — `banned` → false; `empty` → chỉ true khi `resetAt !== null && resetAt <= now`
  - `pickAccount(accounts: Account[], needed: number, now: number, exclude: Set<string>): Account | null` — trong số usable, không bị exclude, `remaining >= needed`, chọn cái **còn ít nhất** (dùng cạn từng account); hoà thì theo thứ tự mảng. Account `empty` đã qua reset thì coi `remaining = limit`.
- Produces (`lib/elevenlabs.ts`):
  - `classifyError(status: number, body: unknown): 'quota' | 'banned' | 'invalid_key' | 'other'`
  - `getSubscription(key: string): Promise<{ used: number; limit: number; resetAt: number | null; status: AccountStatus }>` — `GET /v1/user/subscription`; `resetAt = next_character_count_reset_unix * 1000`; `status`: API trả `free_disabled` → `banned`, `used >= limit` → `empty`, còn lại `ok`. Lỗi HTTP → throw `ElevenError(kind)`.
  - `listVoices(key: string): Promise<Voice[]>` — Adam đứng đầu
  - `tts(key: string, voiceId: string, text: string, model: ModelId, settings: VoiceSettings): Promise<Blob>` — `POST /v1/text-to-speech/{voiceId}?output_format=mp3_44100_128`, header `xi-api-key`; HTTP lỗi → throw `new ElevenError(classifyError(status, body))`
  - `generateSpeech(args: { accounts: Account[]; voiceId: string; text: string; model: ModelId; settings: VoiceSettings; now: number; onTry?: (a: Account) => void; ttsFn?: typeof tts }): Promise<{ audio: Blob; accountId: string; updates: Partial<Record<string, AccountStatus>> }>` — vòng lặp: `pickAccount` (exclude các account đã thử) → `onTry` → `ttsFn(key, voiceId, textForModel(text, model), ...)`; lỗi `quota` → updates[id]='empty', `banned` → 'banned', rồi thử tiếp; lỗi khác → throw. Hết account → throw `ElevenError('all_exhausted')` với message "Hết credit ở tất cả account".
  - `class ElevenError extends Error { kind: string }`
